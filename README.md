Atividade final da disciplina de **Busca em Espaços de Estados** do professor **Sergio Tanaka**.

O projeto resolve o quebra-cabeça 8-Puzzle com três algoritmos de busca:

- **BFS** (Busca em Largura)
- **DFS** (Busca em Profundidade, com limite de profundidade)
- **A\*** (heurística: distância de Manhattan)

## Como executar

```bash
python main.py
```

## Como testar

```bash
pip install pytest
pytest
```
